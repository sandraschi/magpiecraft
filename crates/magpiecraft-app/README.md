# `magpiecraft-app` (L3 Native egui Library Grid & Comics Reader)

Native pure-Rust desktop workstation (`eframe`/`egui`) calling `magpiecraft-core` in-process: multi-kind library grid with covers, native comics/manga reader (spreads, half-page overlap, RTL, prefetch, keyboard navigation), organise plan/diff/undo workspace, multiple skins (Neon Shelf, Paper Library), and external player hand-off (VLC/mpv) for video/audio.
